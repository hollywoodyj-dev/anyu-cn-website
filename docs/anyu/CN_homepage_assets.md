# 中文首页配图说明（与设计稿对齐）

把文件放到 **`public/anyu/home/`** 下，文件名需与下表**完全一致**（小写、连字符）。更新后无需改代码，部署或刷新即可。

## 推荐优先级

### 1. `hero-lifestyle.jpg` / `.webp` / `.png`（**最推荐**，与设计主视觉一致）

- **内容：** 一张图里包含：安语灯、桌面/家居氛围、手机上的子女端界面（与设计稿同构图最佳）。
- **比例：** 竖幅或微竖为主，建议约 **5∶6 ～ 3∶4**（例如 **1200×1500** 或 **1600×2000**），分辨率 **≥1600px 短边** 便于高分屏。
- **格式：** 优先 **`hero-lifestyle.jpg`**，其次 **`.webp`**、**`.png`**（代码按序自动检测）。
- **作用：** 一旦有该文件，首页右侧 Hero 会**整图铺满**，并在**左缘、底缘**用与页面同色的渐变与 `#F8F3EC` 融边。灯与 App 不在 Hero 里叠小卡，而改在下方 **「安语灯与子女端」** 大双卡中展示。

### 2. `lamp.png` / `child-app.png`（**安语灯与子女端**，Hero 下方独立双卡）

- **lamp.png：** 安语灯产品，**透明底 PNG** 更佳；约 **400×600 ～ 800×1200**；第一张大卡右侧主图位。
- **child-app.png：** 子女端界面，竖图约 **9∶16**；第二张大卡右侧，圆角裁切 `object-cover`。

### 3. 版式说明

- **上：** 家庭/场景长图 + 与页面底色 **#F8F3EC** 的 **左缘、底缘** 渐变融边。  
- **下：** 两列大卡片「安语灯」「子女端 App」独立展示，左文右图。

## 顶栏 Logo

- 路径：**`public/anyu/anyu-logo-mark.png`**（与 `app/cn/layout.tsx` 一致）。
- 请使用 **透明底 PNG**；头栏使用 `object-contain`、**不做圆形裁切**，避免误看成黑底。
- 若文件本身带黑底，需从设计导出 **透明背景** 后再覆盖。
