# 中文首页配图说明（与设计稿对齐）

把文件放到 **`public/anyu/home/`** 下，文件名需与下表**完全一致**（小写、连字符）。更新后无需改代码，部署或刷新即可。

## 推荐优先级

### 1. `hero-lifestyle.jpg` 或 `hero-lifestyle.webp`（**最推荐**，与设计主视觉一致）

- **内容：** 一张图里包含：安语灯、桌面/家居氛围、手机上的子女端界面（与设计稿同构图最佳）。
- **比例：** 竖幅或微竖为主，建议约 **5∶6 ～ 3∶4**（例如 **1200×1500** 或 **1600×2000**），分辨率 **≥1600px 短边** 便于高分屏。
- **格式：** 优先 **`hero-lifestyle.jpg`**；若只有 WebP，使用 **`hero-lifestyle.webp`**（代码会自动二选一）。
- **作用：** 一旦有该文件，首页右侧 Hero 会**整图铺满**，不再使用 CSS 拼的三卡示意。

### 2. `lamp.png`（**可选**，无整图时使用）

- **内容：** 安语灯产品图，**透明底 PNG** 最佳。
- **尺寸：** 约 **400×600 ～ 800×1200**，主体居中。
- **作用：** 仅在**未放置** `hero-lifestyle.jpg` 时，替换 Hero 里「灯」卡片的圆形示意，更接实物。

### 3. `child-app.png`（**可选**）

- **内容：** 子女端 App 界面截图（情绪趋势、提醒卡片等），可带手机壳也可纯界面。
- **比例：** 竖图，约 **9∶16** 裁成 **720×1280** 左右即可。
- **作用：** 仅在**未放置** `hero-lifestyle.jpg` 时，嵌入右侧「手机」示意框内，替代当前 CSS 画的折线与卡片。

---

## 当前仓库行为摘要

| 文件 | 行为 |
|------|------|
| 有 `hero-lifestyle.jpg` | 右侧 Hero **只显示该图**（圆角大卡片），与设计「单张主视觉」一致。 |
| 无 `hero-lifestyle.jpg` | 使用内置 **CSS 三卡示意**；若另有 `lamp.png` / `child-app.png` 会分别替换灯区与手机区。 |

资源检测在浏览器端通过 `HEAD` 请求完成，首屏会极短延迟后切换（仅影响有无整图分支）。
