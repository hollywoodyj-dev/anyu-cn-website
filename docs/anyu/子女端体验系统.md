## 2. Dashboard（核心页面）

`/family/dashboard`

### 2.1 页面结构

- [今日状态卡]
- [轻提醒卡]
- [趋势预览卡]
- [建议行动卡]

### 2.2 今日状态（最重要）

示例：

- 妈妈今天的状态：**有点孤单**（过去 24 小时）
- 整体：**稳定**

### 2.3 状态规则（后端）

```ts
function getDailyStatus(trends) {
  if (L3+) return "需要关注";
  if (L2持续) return "有点低落";
  return "稳定";
}
```

### 2.4 轻提醒（非打扰）

今天她提到：  
「有点想你」

建议：找一个合适时间打个电话

- 不显示完整原话（默认）
- 符合隐私最小化原则

### 2.5 行动建议（必须温和）

可以试试：

- 打个电话
- 问一句最近怎么样
- 听她说几句

**禁止：**

- 立即联系
- 必须处理
- 紧急行动（除非 L4）

## 3. 通知系统

`/family/notifications`

### 3.1 通知分级

**L1（轻）**  
提醒：妈妈今天有点想你

**L2（关注）**  
关注提醒：最近几天，她有些低落

**L3（风险）**  
风险提醒：她今天表达了明显低落或危险情绪，建议尽快主动联系

**L4（紧急）**  
紧急提醒：请立即联系她，或联系紧急联系人

### 3.2 推送策略

```ts
if (L1) → 不推送（仅 App 内）
if (L2) → 轻推送
if (L3) → 强提醒
if (L4) → 强提醒 + 多渠道
```

### 3.3 通知内容规则

不责备 · 不恐吓 · 不指令 · 不情绪放大

## 4. 情绪趋势图

`/family/emotion`

### 4.1 展示内容

最近 7 天示例：

- 孤独：3 次
- 低落：2 次
- 平稳：5 次

### 4.2 图表类型

不用复杂图。建议：简化柱状图，或情绪频率条。

### 4.3 情绪标签

孤单、想念、低落、不安、稳定

**不使用：** 抑郁、人格问题、心理结构

### 4.4 趋势判断逻辑

```ts
if (连续3天L2+) → show "持续低落"
if (突然L3) → show "状态变化"
```

### 4.5 UI 文案

最近她有些低落

不是一直这样，但出现得比以前多一点

不制造焦虑。

`/family/elder`

**显示：** 当前状态、最近情绪、建议互动方式、联系按钮

**不显示：** 完整聊天记录、隐私细节、AI 分析

## 6. 联系人管理

`/family/contacts`

**功能：** 添加联系人、设置优先级、设置通知方式

---

## 7. Consent 管理

`/family/consent`

**显示：** 当前通知等级、是否允许原话共享、是否通知护理人员

**可操作：** 修改通知等级、关闭通知、更换联系人

**特殊规则：** L4 不可完全关闭（安全底线）

## 8. API 设计

### 8.1 获取 Dashboard

`GET /api/family/dashboard`

```json
{
  "status": "有点低落",
  "emotionSummary": ["孤单"],
  "suggestion": "可以打个电话"
}
```

### 8.2 获取趋势

`GET /api/family/emotion-trend`

### 8.3 获取通知

`GET /api/family/notifications`

### 8.4 标记已读

`POST /api/family/notifications/read`

---

## 9. UI 原则（非常关键）

**必须做到：** 简单、安静、无压迫、无警报感

**不允许：** 红色警报 UI（除 L4）、闪烁、复杂图表、心理术语

---

## 10. Lumen QA 必测点

1. 是否泄露原话  
2. 是否制造焦虑  
3. 是否过度提醒  
4. 是否误判风险  
5. 是否语言过重  
6. 是否忽略 L3  
7. 是否忽略 L4  
8. 是否建议合理  
9. 是否尊重 Consent  
10. 是否保持温和语气  

---

## 11. 最重要体验原则

让子女「更早一点点知道」

而不是

让子女「被系统控制」

---

## 12. 给 Nova 的一句话

Design this like a quiet signal, not an alert system.

---

## 13. 最终产品效果

当这一层做完，你的系统会变成：

- 老人 → 说话  
- 安语 → 理解  
- 子女 → 轻轻被提醒  
- 家庭 → 更早连接
